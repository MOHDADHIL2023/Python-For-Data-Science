### 🚀 Setup & Execution

### 1. Requirements

Make sure you have Python 3.10+ deployed on your machine. 

### 2. Local Setup

Isolate dependencies using a virtual environment to prevent version mismatches: 

bash

# Clone this repository
git clone https://github.com/MOHDADHIL2023/Python-For-Data-Science.git
cd Python-For-Data-Science

# Initialize and activate the virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install critical science and analytics packages
pip install numpy pandas matplotlib seaborn plotly scikit-learn

Use code with caution.

### 3. Running Scripts & View Artifacts

To execute any individual analytical module or view the embedded interactive visualizations: 

bash

# Run a specific programmatic exercise script
python EX1.py

# Open interactive data visualizations in your default browser
open ex13_cars_scatter.html  # On Windows: start ex13_cars_scatter.html

Use code with caution.
